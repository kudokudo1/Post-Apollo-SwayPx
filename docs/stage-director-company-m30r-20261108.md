## IMPLEMENTATION

Company M30q PR #1516 landed in `The-Post-Apollo-Project`, replacing
two original QML coordinate bugs that previously needed a temporary
modification in SwayPX's M30i CI copy.

M30r adds **one new wrapper** `ci_company_m30r_real_source.py`, a
**CI-only guarded dispatch** and an isolated GitHub workflow to verify the
already-merged Company's original QML in a real Quickshell/SwayPX
headless session. The wrapper reuses the *existing* M30i real Quickshell
geometry/pixel and lifecycle tests but overrides only the reviewed source
SHA and the function that prepares its disposable copy. It **does not
modify either Company source coordinate expression**.

Only read-only `ciM30i*` introspection properties and a test shell file
are inserted into a disposable Company QML copy. The original Company
Git checkout must match its exact immutable commit and QML blob hashes
and remain clean. Old source text is forbidden:
- `mapCanvas.mapToItem(root, 0, 0)`
- `companyFrame.mapToItem(root, 0, 0)`

The tests keep the original normal SwayPX binary (not its special M30o
CI renderer), genuine Quickshell, output pixels and actual layer surface
across **standard → compact → fullscreen → close**. The optional
Company vector bridge remains false and no native MapLibre child is
allowed to start.

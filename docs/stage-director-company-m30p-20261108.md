## IMPLEMENTATION

M30o proved real MapLibre Native Qt v3 rendering inside the actual Company
Quickshell PanelWindow at standard/compact/fullscreen in *separate disposable
CI only*, including 840×540 → 1493×788 → 840×540, camera and PIDFD/XDG
continuity, Wayland pointer, screenshot/content and native close. Its
test-only compositor bypass is **not** in normal SwayPX. It is neither
worldwide street coverage nor a Company runtime deployment.

M30p introduces `tests/stage_director/ci_company_m30p_production_preflight.py`,
a **read-only source contract**, plus a fast GitHub workflow. It validates:
- Original Company Git commit and four exact source blob identities.
- Existing attached Quickshell native sidecar, opt-in optional Wayland
  bridge, and child PID report. No new launcher.
- Existing F11 physical host selection *candidate* and v2 pidfd/ELF
  inode/digest observation. Neither is production rendering authority.
- Existing source-only geometry repair experiment in disposable M30i copy.
- Production `stage_director.c` still reports `scene=OFF input=OFF`,
  and private M30o actor scene hooks are absent from production source.
- Operator-approved executable manifest remains deliberately empty.

The output JSON is a source-grounded blocker matrix, **not a production
health sensor**. The CLI always sets `production_ready=false` and
`production_activation=REFUSED`; `--require-production-ready`
exits with code 3, as a positive fail-closed test. Unknown source drift
exits 2, rather than automatically claiming a new implementation is safe.

## WATCH OUT FOR

Two **original Company-owned QML defects are still unlanded**:
- `CompanyCoveragePane.qml` calls
  `mapCanvas.mapToItem(root,0,0)` where prior native CI observed a
  wrong ancestor-relative y transform. The disposable M30i witness
  used a guarded sum of exact untransformed ancestor item offsets.
- `CompanyNetworkW.qml` calls
  `companyFrame.mapToItem(root,0,0)`, passing a Quickshell
  `PanelWindow` to `Item.mapToItem(Item)`; the disposable CI
  proof used `mapToItem(null,0,0)` rather than the invalid target.
  These are **proposed fixes**, not approved or applied to actual Company.

Two **Stage Director/operations blockers** remain:
- Production executable SHA256 manifest is deliberately empty; never
  derive/approve a digest from runtime metadata, CI or an unreviewed ELF.
- A production selected-host native **render/input/clip admission** chain
  is still absent. M24 physical selection, M28 pidfd, M29 same-inode and
  M30 digest observation are candidate evidence only, not scene authority.

Further unresolved verification includes the actual native source
resizing lifecycle in production, multi-output/scale/transient popup
and keyboard/focus containment, tile licensing/attribution and privacy,
and operator visual acceptance. Online tiles would disclose viewer
network/map position and require separate opt-in. None of the public
